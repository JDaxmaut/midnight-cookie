# 🍪 MidnightCookie Theme for BetterDiscord

## Описание
**MidnightCookie** - это элегантная темная тема для Discord, вдохновленная теплыми тонами печенья и глубокими полуночными синими оттенками. Тема сочетает в себе уютную атмосферу с современным минималистичным дизайном.

## ✨ Особенности

### 🎨 Цветовая схема
- **Основные цвета**: Глубокие полуночные синие тона (hsl(220, 15%, 12%))
- **Акцентные цвета**: Теплые коричневые оттенки печенья (hsl(28, 80%, 60%))
- **Фон**: Градиент от темно-коричневого к полуночному синему
- **Текст**: Высококонтрастный белый для лучшей читаемости

### 🚀 Функциональность
- **Адаптивный дизайн** с поддержкой мобильных устройств
- **Плавные анимации** и переходы (300ms)
- **Кастомный скроллбар** в стиле темы
- **Hover эффекты** для интерактивных элементов
- **Поддержка светлой и темной темы**
- **Улучшенная доступность** с поддержкой высокого контраста

### 🎯 Элементы интерфейса
- **Сообщения**: Скругленные углы с hover эффектами
- **Каналы**: Плавные анимации при наведении
- **Кнопки**: Современный дизайн с тенями
- **Поля ввода**: Стилизованные textarea с фокусом
- **Карточки**: Элегантные hover эффекты

## 📁 Файлы темы

### 2. `midnight-source.css`

## 🛠️ Установка

### Способ 1: Через BetterDiscord
1. Откройте Discord
2. Перейдите в **User Settings** → **BetterDiscord** → **Themes**
3. Нажмите **Open Themes Folder**
4. Скопируйте файл `MidnightCookie.theme.css` в папку тем
5. Перезапустите Discord
6. Активируйте тему в настройках

### Способ 2: Ручная установка
1. Скопируйте `MidnightCookie.theme.css` в папку:
   - **Windows**: `%APPDATA%\BetterDiscord\themes\`
   - **macOS**: `~/Library/Application Support/BetterDiscord/themes/`
   - **Linux**: `~/.config/BetterDiscord/themes/`

2. Перезапустите Discord

## ⚙️ Настройка

### Основные переменные
```css
:root {
  --app-bg: rgb(25, 20, 18);           /* Основной фон */
  --accent-hue: 28;                     /* Оттенок акцента */
  --accent-saturation: 80%;             /* Насыщенность акцента */
  --accent-lightness: 60%;              /* Яркость акцента */
  --app-radius: 8px;                    /* Радиус скругления */
  --app-blur: 12px;                     /* Размытие фона */
}
```

### Кастомизация цветов
Вы можете изменить цвета, отредактировав переменные в файле темы:

```css
:root {
  --midnight-primary: hsl(220, 15%, 12%);      /* Основной цвет */
  --midnight-secondary: hsl(225, 12%, 15%);    /* Вторичный цвет */
  --midnight-accent: hsl(28, 80%, 60%);        /* Акцентный цвет */
}
```

## 🔧 Устранение неполадок

### Тема не загружается
1. Проверьте, что файл находится в правильной папке
2. Убедитесь, что BetterDiscord установлен и активирован
3. Перезапустите Discord

### Проблемы с отображением
1. Проверьте консоль на наличие ошибок CSS
2. Убедитесь, что нет конфликтов с другими темами
3. Попробуйте отключить другие темы

### Медленная работа
1. Отключите анимации в настройках системы
2. Уменьшите значение `--app-blur`
3. Отключите сложные эффекты
